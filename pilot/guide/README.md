# 라벨링 가이드 — 문서 관리

`aivoucher-labelling_22.05.27.pdf` (2022년, Keynote 제작)를 대체하는 문서입니다.
원본 PDF는 수정할 수 없어(원본 `.key` 파일 미보유) 편집 가능한 형태로 다시 만들었습니다.

## 파일 구성

```
guide/
├─ README.md              이 파일 — 문서 관리·변경 이력
├─ LABELING_GUIDE.md      본문 — 라벨링 기준서
├─ CHANGES_FROM_2022.md   2022년 PDF 대비 변경점과 근거
└─ assets/
   ├─ parts/              부품별 참고 사진 (업체 제공분을 여기 넣습니다)
   ├─ panels/             반별 전경 사진
   └─ _원본추출/           2022 PDF 에서 추출한 사진 56장 + 페이지 렌더
```

## 사진을 추가하는 방법

업체에서 실물 사진을 받으면 다음 순서로 넣습니다.

1. 파일을 `assets/parts/` 에 넣습니다. 이름 규칙은 아래와 같습니다.

   ```
   <부품키>_<번호>.jpg          예: ct_transformer_01.jpg
   <부품키>_구분_<설명>.jpg      예: mof_구분_하단단자.jpg
   ```

   부품키는 `LABELING_GUIDE.md` 의 클래스 표에 있는 영문 키를 씁니다.

2. `LABELING_GUIDE.md` 에서 해당 부품 항목을 찾아 `참고 사진` 줄을 고칩니다.

   ```markdown
   참고 사진: *(미확보 — 업체 제공 예정)*
   ```
   를 이렇게 바꿉니다.
   ```markdown
   참고 사진: ![변류기](assets/parts/ct_transformer_01.jpg)
   ```

3. 사진으로 새로 알게 된 판별 근거가 있으면 `판별 기준` 항목에 한 줄 추가하고,
   `CHANGES_FROM_2022.md` 에 날짜와 함께 기록합니다.

## 아직 채우지 못한 것

문서 안에서 `**[미확정]**` 으로 표시한 부분입니다. 추측으로 채우지 않았습니다.

| 항목 | 필요한 것 | 확인처 |
|---|---|---|
| 부품별 참고 사진 | 실물 사진 | 업체 (제공 예정) |
| 에폭시 표면 절대 허용온도 | 절연 등급별 기준 | 업체 기술고문 |
| 철심부 위험 판정선 | 정상 범위(110~120°C) 위의 위험선 | 업체 기술고문 |
| 본체류 절대 임계 | 변압기·변류기·PT·CT·MCCB 등 | 업체 기술고문 |
| 변압기/변류기 분리 여부 | 현장 실물 구성 확인 | 현장 |
| MOF/PT 회로상 위치 | 반별 배치도 | 도면 |

## PDF 로 뽑으려면

```bash
pip install md2pdf          # 또는 pandoc
pandoc LABELING_GUIDE.md -o 라벨링가이드_v2.pdf --pdf-engine=xelatex \
  -V mainfont="Malgun Gothic"
```

VS Code 의 Markdown Preview 에서 인쇄해도 됩니다.
