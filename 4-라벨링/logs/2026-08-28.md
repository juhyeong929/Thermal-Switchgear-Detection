# 2026-08-28 — 시험 30장 선정 계보 기록

## 문제

시험 30장에 대해 **뽑힌 이유는 한 줄뿐이었고, 탈락 이유는 아예 기록이 없었다.**
`trial_set.csv` 의 reason 은 "몰드변압기 접촉부 단위 검증 · 시드 후보" 정도였고,
38,957 -> 400 -> 30 으로 줄어드는 과정에서 무엇이 왜 빠졌는지 남지 않았다.

검증·인증에서 "표본을 임의로 고른 것 아닌가"라는 질문에 답할 수 없는 상태였다.

# 진행 판단 — 조사보다 시험 라벨링을 먼저 한다 (DEC-019)

## DECISION

C·B·D 조사가 끝난 시점에서 **여러 OQ 가 "조사 완료·판정 대기"** 상태다.
여기서 OQ 를 전부 닫은 뒤 시험하는 것보다, **현재 확정된 규칙으로 시험을 먼저
돌리는 것이 가치가 크다.** 시험 결과가 나와야 답할 수 있는 질문이 있기 때문이다 —
*가이드 v1 이 실제 라벨러 사이에서 재현되는가.*

순서: ① 30장 시험 → ② OQ-015/016/017/010 판정 → ③ agreement → ④ 지침서 v2 → ⑤ 400장 seed
③은 ①을 기다리지 않는다. **둘은 서로 막지 않는다.**

## FACT — 열린 OQ 중 1차 시험 30장을 막는 항목은 0건

지침서 v1 이 미확정 항목을 "그리지 않는다 / Skip 한다" 로 처리하도록 쓰였다
(접촉부 7종 = 그리지 않음, 엘보 = 검수 대상 분류).
`open_questions.csv` 에 열 2개를 추가해 이 사실을 항목별로 기록했다.

```
impact                    무엇을 결정하는 질문인가
blocks_current_labeling   지금 진행 중인 라벨링을 막는가
```

## DECISION — 잠정 정책 4건 (닫지 않는다. 지금 무엇을 쓰는지만 기록한다)

| OQ | 잠정 정책 | 결정하지 않은 것 |
|---|---|---|
| OQ-017 온도 | 지금 결정하지 않음. `future_model_input` · 라벨링 blocker 아님 | 온도 사용 여부 |
| OQ-010 OSD | 마스킹 보류. 면적 5% 초과 49박스(1.2%)·최대 20.6% | 마스킹 여부·임계값·49박스 처리 |
| OQ-016 누수 | cluster split 유지. 세션 분할은 실측 후 기각 | 42.8% 교차의 수용 여부 |
| OQ-015 비율 | 70/15/15 를 **기본 정책**으로 적용 (69.8/15.0/15.3 구현) | 비율의 정당화 |

**OQ-010 의 71.7% 는 오염률이 아니다.** OSD 픽셀이 한 번이라도 든 박스가 2,994개일 뿐,
대부분은 큰 박스를 얇은 선이 스친 것이다. 면적 25% 초과는 0건.

**OQ-017 의 성과는 "IR1 에서 온도 추출이 가능하다"를 확인한 것까지**다.
IR2/IR3 실패(APP1 세그먼트 없음)는 객체 라벨링의 blocker 가 아니다.

## 추가 — 작업시간 기록

`agreement.py` 는 개수 일치 · mIoU · Kappa · Skip 을 재지만 실무 지표 하나가 빠져 있었다.
**30장에 실제로 얼마나 걸렸는가.** 모르면 400장 물량을 추정할 근거가 없다.

- `annotator_*/time_log.csv` 서식 5개 생성 (`trial_set_export.make_annotator_packets()`)
  — 구간별 `start`/`end`/`minutes`/`cases_done`. 자정 넘김·휴식 분리 처리
- `agreement.py` 가 함께 집계 → `reports/labeling/trial_time_<날짜>.csv`
  (라벨러별 총분 · 분/장 · 400장 추정), 기록이 없으면 추정하지 않고 그렇게 말한다
- 지침서 문구를 "속도를 재지 않습니다" → **"빨리 하실 필요 없습니다. 실제로 걸린 시간을
  적으세요"** 로 고쳤다. **속도 평가가 아니라 물량 산정이다.**

## 라벨러에게 전달한 지시

> 시험셋 30장을 각자 **독립적으로** 라벨링한다. 다른 라벨러의 결과를 보지 않는다.
> 기존 reference annotation 도 보지 않는다. 애매한 객체는 **개인적으로 규칙을 만들지 말고**
> Skip 로그에 남긴다. 걸린 시간을 `time_log.csv` 에 적는다.

- 정본 라벨 · 격리 목록 · 분할 파일 · 30장 구성 — 무수정
- 기존 `skip_log.csv` 5개 (작업 중인 사람의 기록을 덮어쓰지 않는다)
