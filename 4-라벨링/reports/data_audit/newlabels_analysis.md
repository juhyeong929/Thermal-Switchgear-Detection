# POSSIBLE RULE — OQ-006 경계 규칙 확정에 쓸 사례

## R-1. 케이블헤드(#14) — 어디부터 어디까지인가

`6ban_zoom_0/1.png` 이 실물 근거를 준다. 관측된 패턴:
- 박스가 **리브(shed) 적층부 전체**를 세로로 감싼다
- 종횡비 중앙 **0.19**, IQR 0.06 — 387개가 거의 같은 비율이다. 규칙이 이미 서 있다
- 상단 도체(엘보·스터브)를 **포함한 경우와 제외한 경우가 둘 다 있다** → 확정 필요

제안 초안: `리브 적층부 상단부터 하단 베이스까지. 상부 도체·엘보는 제외한다`
— 다수 사례가 이 형태이고, 포함한 사례는 별도 박스로 분리되어 있었다.

## R-2. 접촉부(contact) 계열 — 단자군 단위로 끊는다

9ban 이 가장 명확한 사례다(`9ban_boxes.png`).
```
MCCB 본체        -> 박스 1개 (기기 외곽)
좌측 단자군      -> 접촉부 박스 1개
우측 단자군      -> 접촉부 박스 1개
```
개별 단자 하나하나가 아니라 **한쪽 단자군을 한 박스로** 묶는다.
MCCB 접촉부 종횡비 IQR 0.09 로 1,778개가 일관적이다.

정본 P1 의 몰드변압기 접촉부(면적 중앙 0.0121)와 9ban MCCB 접촉부(0.0100)의
크기대가 비슷하다 — 접촉부 클래스의 표준 크기대로 삼을 수 있다.

## R-3. 잘림 — 2변 이상 접촉은 사실상 박스를 치지 않았다

3,339박스 중 2변 이상 프레임 접촉이 **2건**뿐이다.
DEC-007 의 `노출 30% 미만이면 생략` 기준과 방향이 일치한다.
1변 접촉(888건)은 잘렸어도 형태 식별이 가능해 박스를 친 사례로 볼 수 있다.

→ 규칙 초안: `1변 접촉은 truncated=true 로 남기고, 2변 이상 접촉은 노출 비율을 재본다`

## R-4. 초소형 하한선의 실측 근거

초소형 21건이 전부 9ban MCCB 접촉부이며, 그 클래스의 면적 p05 는 **0.0029** 다.
DEC-004 의 `너무 작아서 식별 불가 -> 생략` 을 수치로 바꿀 때
**정규화 면적 0.003 (320x240 에서 약 230px, 대략 15x15px)** 근처를 후보로 검토할 수 있다.

단, 이는 관측값이지 가이드에 있는 수치가 아니다. 새 임계값 신설은 사람 판단이 필요하다.

## R-5. 그룹 박스 금지 규칙은 이미 지켜지고 있다

동일 클래스 IoU ≥ 0.6 중첩이 3,339박스 중 **1건**이다.
