## 무엇을 묻고 있나

같은 장면이면 val/test 지표가 부풀고, 다른 장면이면 아무 문제 없다. 지금까지 육안 확인은 4건뿐이었다.

## 표본 설계

코사인 구간은 **실제 분포의 4분위**로 잡았다 (임의 구간이 아니다).

```
0.9000 ~ 0.9079 ~ 0.9155 ~ 0.9228 ~ 0.9300
```

층화 축: `반 × 카메라 × 세션관계(same/diff) × 코사인 구간` → 층 139개

**비례 배분이며 균등 배분이 아니다.** 전 층에 1개씩 주면 5.68% 층과 0.01% 층이 같은 무게를
갖는다 — 그건 층화가 아니다. 그래서:

- 모집단의 0.5% 이상인 **주요 층** → 비례 배분 (최소 1)
- 나머지 **잔층 115개** → 하나로 묶어 비례 몫만큼, 반별로 나눠 추출

결과 **101쌍** (모집단의 0.245%) · 같은 세션 66 / 다른 세션 35.
층별 표본 수와 모집단 비중은 `summary.csv`.

## 판정 방법

`visual_review.csv` 의 `verdict` 칸에 **넷 중 하나**를 적는다.

| 값 | 정의 |
|---|---|
| `SAME_SCENE` | 사실상 동일한 시야·대상. 미세 이동 또는 미세 촬영 차이만 |
| `NEAR_DUPLICATE` | 같은 대상을 거의 동일한 구도로 찍었으나 명백히 다른 프레임·촬영 상태 |
| `DIFFERENT_SCENE` | 시야·대상·구성이 실질적으로 다름 |
| `UNCERTAIN` | 두 장만으로 판정하기 어려움 |

특히 다음 둘을 나눠 본다.

- **같은 세션인데 `DIFFERENT_SCENE`** — 세션이 곧 장면이 아니라는 증거
- **다른 세션인데 `SAME_SCENE`** — 세션 단위 분할로도 못 막았을 누수

세션과 cluster 는 같은 의미가 아니다. **"같은 세션이면 누수" 로 결론내지 않는다.**

## 판정 전에 먼저 알아야 할 것 — 0.90~0.93 은 잡음에 가깝다 **[일부 정정됨 · 아래 참조]**

표본을 만들면서 측정한 것이다. **무작위로 고른 두 장**(같은 반·같은 카메라, 아무 관계 없음)의
유사도 분포다.

| 무작위 쌍 | p50 | p90 | ≥0.90 | **0.90~0.93 안에 드는 비율** |
|---|---:|---:|---:|---:|
| 같은 세션 | 0.8299 | 0.9028 | 11.0% | **7.2%** |
| 다른 세션 | 0.8562 | 0.9106 | 17.2% | **15.5%** |

해밍도 마찬가지다 — 무작위 쌍의 **24.8%(같은 세션) / 13.9%(다른 세션)** 가 이미 해밍≤22 다.

> **즉 `해밍≤22 · 코사인 0.90~0.93` 은 중복의 강한 증거가 아니다.**
> 아무 관계 없는 두 장도 상당 비율로 이 조건에 든다.
> 따라서 **42.8% 를 '누수율' 로 읽으면 안 된다** — 그 숫자는 애초에 약한 신호 위에서 세어진 것이다.

이것은 판정을 대신하지 않는다. 다만 표본에서 `DIFFERENT_SCENE` 이 많이 나오더라도
그것이 이상한 일이 아니라는 뜻이며, 반대로 `SAME_SCENE` 이 나오면 그만큼 무겁게 봐야 한다.

> ### [정정 2026-09-01] 이 절의 결론은 절반만 맞았다
>
> 101쌍 판정 결과, **밴드를 하나로 뭉뚱그린 것이 잘못이었다.**
>
> | 코사인 | 실제 위험 비율 |
> |---|---:|
> | 0.9000~0.9079 | **0.0%** |
> | 0.9079~0.9155 | **4.0%** |
> | 0.9155~0.9228 | **37.0%** |
> | 0.9228~0.9300 | **44.0%** |
>
> **하단은 정말 잡음이었지만 상단은 아니었다.** 무작위 대조는 밴드 전체의 평균을 봤고,
> 그 평균이 상단의 위험을 가렸다. 육안 판정 없이는 알 수 없는 구조였다.
>
> "42.8% 를 누수율로 읽으면 안 된다" 는 여전히 맞다 — 실측 추정은 20.0% 다.
> 그러나 **"위험이 잡음 수준" 이라는 결론은 철회한다.** → `RESULT.md` · `DEC-023`

## 예비 관찰 (판정 아님)

가장 위험한 구간(0.9228~0.93 · 같은 세션)에서 2쌍을 열어 봤다 — `pair_0007`(P1·IR2),
`pair_0012`(P9·IR2). 둘 다 **넓은 평탄 열영역 + 동일한 FLIR OSD 배치**가 화면을 지배하고,
구조물의 구도는 서로 달랐다. 이 관찰이 위 정량 측정의 계기였다.
**2건은 판정이 아니다.** 101쌍 전체 판정으로 대체되어야 한다.

## 결과를 읽는 법

누수율 하나로 요약하지 않는다. 최소 다음을 계산한다.

```
same_scene_rate · different_scene_rate · uncertain_rate
same_scene_among_cross_split
same_scene_by_similarity_bin
same_scene_by_panel · by_camera · by_session_relation
```

그리고 세 가지를 따로 기록한다.

| 관찰 | 뜻 |
|---|---|
| cluster 가 다른데 `SAME_SCENE` | 현재 cluster 규칙이 동일 장면을 놓쳤을 가능성 |
| cluster 가 같은데 split 이 다름 | **명백한 누수** — 지금 표본에서는 0건 |
| `DIFFERENT_SCENE` 인데 cluster 가 합쳐짐 | 과병합 가능성 (별도 기록) |

## 결론 분기

| | 조건 | 결론 |
|---|---|---|
| **CASE A** | `SAME_SCENE` 거의 없음 | 현재 cluster split 유지 근거 강화 |
| **CASE B** | 적지만 존재 | 잔여 미탐지 가능성 기록 · 보수적 처리 검토 |
| **CASE C** | 상당수 존재 | **cluster split 최종 확정하지 않음** · threshold/feature/grouping 재검토 |
| **CASE D** | `UNCERTAIN` 이 많음 | 더 명확한 시각 검증 기준이 필요하다고 기록 |

## 하지 않은 것

새 clustering 을 만들지 않았다. cluster_id 를 바꾸지 않았다. split 을 바꾸지 않았다.
원본 이미지를 수정하지 않았다. **4건 표본으로 OQ-016 을 닫지 않았다.**
