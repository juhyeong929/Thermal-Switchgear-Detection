## 배포 전 (검수자)

```
[ ] 반별로 CVAT task 를 나눴는가 — task 이름 = "P6 · P6-VCB반" 형식
       generated/cvat_tasks.csv 의 cvat_task_name 을 그대로 쓴다
[ ] 각 task 에 **그 반의** 라벨 정의를 넣었는가
       generated/cvat_labels/<PID>.json 을 Raw 탭에 붙여넣는다 (반마다 다르다)
       속성(truncated / ignore / 촬영유형)은 이 파일에 이미 들어 있다
[ ] 라벨러 화면에서 박스 속성 칸이 실제로 보이는지 눈으로 확인했는가
[ ] 라벨러에게 자기 반 이름과 배포 클래스 목록을 알려 줬는가 (A-1)
       generated/panel_class_table.md 의 해당 행을 그대로 전달한다
[ ] 기존 라벨을 pre-annotation 으로 넣지 않았는가  ← 넣으면 측정이 무의미해진다
[ ] status_check.py 의 [5-1] 시드 정합성이 전부 OK 인가  ← 정책 변경 미반영을 잡는다
```

`status_check.py` 로 배포본 상태를 확인할 수 있다 — 이미지 30 · 실화상 22 ·
`classes.txt` 28줄 v2 일치 · `cvat_labels.json` 있음.

## A·B·C 결과에서 나온 것 — D·E 에게 특별히 말해 둘 것

**`scope=object` 를 쓸 수 있다는 것을 다시 알려 준다.**
A · B · C **세 명 모두** `scope=object` 사용 0회였다. Skip 26건이 전부 `scope=image` 다.
3/3 이면 개인 성향이 아니라 문구 문제다. 한 장에 박스 6개가 있고 그중 하나만
애매해도 통째로 빠지면 비교할 표본이 사라진다.

> "한 장에서 **일부만** 애매하면 나머지는 그리고, 그 하나만 `scope=object` 로 적어 주세요.
> 장 전체를 못 하겠을 때만 `scope=image` 입니다."

이것은 규칙 변경이 아니라 **v1 에 이미 있는 항목을 다시 안내하는 것**이다.
