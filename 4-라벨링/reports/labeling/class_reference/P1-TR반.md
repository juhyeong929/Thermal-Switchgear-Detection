# P1-TR반 — 부품 식별 참조

> 이 카드는 **무엇을 그릴지 정하기 전에 무엇인지 알아보기 위한** 자료다.
> 경계 규칙은 지침서를 보고, 여기서는 부품 종류만 확인한다.

## 이 반에서 그리는 것 — 4종

- **철심부** (#01) — 세는 단위: 부품 하나를 통째로 감싼다  
  배전반 내 위치때문에 잘 안보임
- **에폭시 표면** (#02) — 세는 단위: 부품 하나를 통째로 감싼다
- **몰드변압기 접촉부** (#03) — 세는 단위: 볼트로 조여진 접속 지점 하나하나
- **소음기부착형 전력퓨즈** (#11) — 세는 단위: 부품 하나를 통째로 감싼다  
  TR 반 · PF&PT 반 공통

## 그리지 않는 것 (전 반 공통)

- 부스바 — 길게 뻗은 도체 막대
- 케이블 — 전선 자체 (**케이블헤드와 다르다**)
- ACB 접촉부
