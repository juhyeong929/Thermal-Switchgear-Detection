# DEC-012 — 케이블헤드(#14) 경계 규칙: 사례 분석과 부분 확정

## 날짜
2026-08-27

## 문제
가이드 v2 는 P6·CNCV 반의 `분기 접촉부` 를 `케이블헤드` 로 명칭 통일했다.
P6 참고 라벨에 구 class 15 가 387개 있어 승계는 가능하지만,
**박스가 어디까지 가야 하는지**가 원칙 문구만으로는 정해지지 않았다 (OQ-006 / NQ-4).

## 관찰 — P6 참고 라벨 387건 전수 측정

387박스 / 177장 / 5개 세션 / 163개 클러스터.
기존 라벨은 `reference` 등급이며 **정답으로 취급하지 않았다**(DEC-011).

## 구성 요소별 판단

근거가 없으면 `UNKNOWN` 으로 둔다. 추정으로 채우지 않는다.

| 요소 | 판단 | 근거 |
|---|---|---|
| 리브(shed) 적층부 | **INCLUDE** | 387건 전부 포함. 예외 없음 |
| 상부 캡·헤드부 | **INCLUDE** | case_02 에서 명확. 다수 사례가 캡까지 포함 |
| 상부 수직 도체·리드 | **CONDITIONAL** | case_01·case_03(가운데)는 포함, case_03(왼쪽)·case_04(왼쪽)는 제외. **관행이 갈린다** |
| 엘보 | **UNKNOWN** | 대부분 박스에 들어가지 않는다. case_04 는 별도 박스로 잡았다. 사례 1건으로는 판단 불가 |
| 하부 도체·스프링 | **CONDITIONAL** | case_02 는 명확히 제외. 다만 하단 프레임 접촉이 92건이라 잘려서 안 보인 경우와 구분되지 않는다 |
| 베이스·취부 구조 | **UNKNOWN** | 사례에서 일관된 처리를 확인하지 못했다 |
| 주변 배선 | **EXCLUDE** | 어떤 사례도 포함하지 않았다 |
| 인접 부스바·프레임 구조 | **EXCLUDE** | 어떤 사례도 포함하지 않았다 |

## 확정한 것

1. **리브 적층부와 상부 캡은 항상 포함한다.** 387건 전수에서 예외가 없다.
2. **주변 배선과 인접 부스바·프레임 구조는 포함하지 않는다.**
3. **같은 인스턴스에 의미가 겹치는 박스를 두 개 그리지 않는다.**
   `[케이블헤드 전체]` 와 `[케이블헤드 상단부]` 를 동시에 그리지 않는다 (case_04·case_05).
   서로 다른 객체라면 각각 그린다.
4. **한 조(組)에 한 박스.** 나란한 세 조가 보이면 박스도 세 개다 (case_05 가 반례).

## 확정하지 않은 것 — 그리고 그 이유

### 상부 도체 포함 여부 — **확정 불가**
기존 관행이 갈린다. case_01 은 도체를 길게 포함했고, case_03 왼쪽은 리브만 잡았다.
같은 프레임 안에서도 갈린 사례(case_03, 높이비 2.47)가 있다.

**한쪽을 고르려면 "케이블헤드가 어느 부품인가"에 대한 설비 판단이 필요하다.**
현재 데이터만으로는 어느 쪽이 가이드 의도인지 알 수 없다.

여기에는 더 근본적인 의문이 깔려 있다. 구 명칭은 `분기 접촉부`(분기 지점의 접촉부)이고
v2 명칭은 `케이블헤드`(케이블 종단접속재)다. **두 이름이 가리키는 물리적 범위가 다를 수 있다.**
기존 박스가 도체를 포함한 것은 `분기 접촉부` 기준으로는 자연스럽지만
`케이블헤드` 기준으로는 과할 수 있다. → NQ-8

### 엘보 포함 여부 — **확정 불가**
사례 1건(case_04)뿐이고, 그 1건도 별도 박스로 처리했다. 근거가 부족하다.

### 작은 객체 하한 — 이번 범위 아님
DEC-011 대로 `검토 후보` 로 남긴다. 새 픽셀 임계값을 넣지 않았다.

## 기존 참고 라벨과 새 규칙이 어긋나는 사례

숨기지 않고 기록한다.

| 사례 | 확정 규칙 | 기존 라벨 | 어긋남 |
|---|---|---|---|
| case_04 | 같은 인스턴스에 겹치는 박스 금지 | 오른쪽에 큰 박스 + 엘보 박스 | **위반** |
| case_05 | 한 조에 한 박스 | 오른쪽 한 조에 박스 2개 중첩 | **위반** |
| case_06 | 주변 구조 미포함 / 케이블헤드 형태 | 종횡비 1.27 의 넓은 박스, OSD 겹침 | **형태 이탈 — 오라벨 의심** |
| 전체 | — | 화면에 보이는데 미라벨된 애자 다수 (case_06 등) | NQ-1 과 동일 정황 |

387건 중 위반이 확인된 것은 **4박스(중첩) + case_06 유형**이다.
**일괄 수정하지 않는다.** 참고 등급 그대로 두고 기록만 남긴다.

## 라벨러용 문구 — 초안 (배포 불가)

근거가 확정된 항목만 채웠다. 빈 칸은 비워 둔다.

```
[케이블헤드 #14]

포함:
- 리브(shed) 적층부 전체
- 상부 캡·헤드부

제외:
- 주변 배선
- 인접 부스바·프레임 구조

bbox 기준:
- 회전·확대율과 무관하게 보이는 픽셀을 감싸는 최소 사각형
- 나란한 조(組)마다 박스 하나. 한 조를 여러 박스로 쪼개지 않는다
- 같은 인스턴스에 의미가 겹치는 박스를 두 개 그리지 않는다

상부 도체:
- (미확정 — NQ-8 해소 전까지 라벨러 판단에 맡기지 않는다)

엘보:
- (미확정 — 근거 부족)

애매한 경우:
- Skip 하고 검수 목록에 올린다. 임의로 추측하지 않는다

Ignore 조건:
- DEC-004 / DEC-007 을 따른다
```

**이 문구는 배포하지 않는다.** 상부 도체 항목이 비어 있는 채로 배포하면
라벨러마다 다르게 판단하게 되고, 그것이 바로 이번에 관측한 편차의 원인이다.

- 참고 라벨 387건은 손대지 않았다
