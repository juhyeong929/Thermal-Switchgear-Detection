# DEC-004 — 라벨링 제외 / Ignore 정책

## 날짜
2026-08-27

## 결정 내용
가이드 v2 와 파이프라인 문서의 제외 규칙을 `schemas/labeling_rules.py` 한 곳에 코드로
고정하고, 문서는 이 파일을 인용한다. **가이드·파이프라인에 없는 임계값을 새로 만들지 않는다.**

## 정책

### 1. 항상 제외 — 어떤 반에서도 박스를 그리지 않는다

| 클래스 | 가이드 사유 |
|---|---|
| 부스바 (#21) | 일정한 패턴이 없어 탐지 정확도가 떨어짐 |
| 케이블 (#22) | 일정한 패턴이 없어 탐지 정확도가 떨어짐 |
| ACB 접촉부 (#27) | 배전반 내 위치때문에 잘 안보임 |

케이블(#22, 제외)과 케이블헤드(#14, 가공)는 다른 클래스다. 혼동하지 않는다.

### 2. 식별 가능한 경우만 라벨 (가이드 '주의')

| 클래스 | 가이드 사유 |
|---|---|
| 철심부 (#01) | 배전반 내 위치때문에 잘 안보임 |
| 인입선로 접촉부 (#20) | 반사 때문에 탐지 정확도가 떨어짐 |
| CT 접촉부 (#26) | 배전반 내 위치때문에 잘 안보임 |
| MCCB 접촉부 (#28) | 다른 접촉부와 구분이 안됨 |

**판별 불가 → 미라벨 / Ignore.**
"안 보이니까 없다" 또는 "안 보이니까 정상이다" 로 기록하지 않는다.
이 세 가지는 서로 다른 상태이며, 섞이면 나중에 되돌릴 수 없다.

### 3. 일반 Ignore

- 너무 작아서 부품 종류를 식별할 수 없음
- 다른 부품에 완전히 가려져 형태를 확인할 수 없음
- 프레임 밖으로 대부분 잘림 (아래 4항)
- 동일 부품이 겹쳐 개별 경계를 신뢰성 있게 구분할 수 없음
  → **그룹 박스로 묶지 않는다.** 현 단계에서 그룹 박스는 허용하지 않으며 Ignore 처리한다

### 4. 잘림 기준 — "무엇의 70%"인가

파이프라인 문서 원문: *"해당 부품의 정상 촬영 시 전체 면적 대비, 화면에 노출된 영역이
30% 미만(= 70% 이상 잘림)이면 박스 생략"*

명확히 하면:

```
분모 = 그 부품을 잘리지 않게 촬영했을 때의 전체 면적
분자 = 지금 이 프레임 안에 보이는 영역의 면적

노출 비율 <  30%  ->  박스 생략 (Ignore)
노출 비율 >= 30%  ->  보이는 영역만 박스, truncated = true
```

화면 좌표 기준이 아니라 **부품의 원래 크기 기준**이다. 라벨러는 같은 반의 잘리지 않은
다른 프레임을 기준 삼아 눈으로 추정한다. 자동 계산식은 없다.
→ 변경 이력과 선택 근거: `DEC-007-truncation-threshold.md`
→ OQ-005: 라벨러 간 추정 편차는 STEP 12 일치도 검증에서 측정한다.

### 5. 속성은 서로 다른 필드로 기록

| 속성 | 의미 |
|---|---|
| `truncated` | 프레임 밖으로 잘렸으나 식별 가능 — 보이는 영역만 박스 |
| `occluded` | 다른 부품에 가려짐 |
| `ignore` | 판별 불가 또는 경계 구분 불가 — 학습에서 제외 |

하나의 플래그로 뭉치지 않는다. 라벨링 툴에서 별도 필드로 분리해 기록한다.

### 6. 박스 경계
회전·확대율과 무관하게 **보이는 픽셀을 감싸는 최소 사각형**.

### 7. 이미지 단위 메타데이터
샷 타입(클로즈업 / 중거리 / 전체)을 이미지마다 태깅한다.
샷 타입별 성능 편차를 보려면 필수다.
