# DEC-007 — 잘림(truncated) 판정 기준 구체화

## 날짜
2026-08-27

## 결정 내용
프레임 밖 잘림 판정을 **재현 가능한 수치 기준**으로 구체화한다.

```
분모 = 그 부품을 잘리지 않게 촬영했을 때 추정되는 전체 면적
분자 = 지금 이 프레임 안에 보이는 영역의 면적

노출 비율 <  30%  ->  박스 생략 (Ignore)
노출 비율 >= 30%  ->  보이는 영역만 박스, truncated = true
```

## 변경 전 → 변경 후

| | 표현 |
|---|---|
| **변경 전** | "프레임 밖으로 대부분 잘린 경우 제외" |
| **변경 후** | "정상 촬영 시 추정되는 객체 전체 면적 대비 70% 이상이 프레임 밖으로 벗어난 경우(= 노출 30% 미만) Ignore" |

## 문제
"대부분"은 라벨러마다 다르게 읽힌다. 같은 프레임을 두고 한 사람은 박스를 치고 다른
사람은 생략하면, 그 차이가 그대로 일치도 지표를 깎아먹고 원인도 찾기 어렵다.
검증·인증 과정에서 "이 박스는 왜 생략했는가"에 답하려면 수치 기준이 필요하다.

## 검토한 선택지
1. **"대부분" 을 그대로 둔다** — 라벨러 판단에 맡김. 재현 불가. 기각
2. **화면(프레임) 면적 대비 비율로 정의** — 계산은 쉽지만 의미가 틀린다.
   같은 부품이라도 클로즈업이면 화면을 가득 채우고 전체 샷이면 작게 나오므로,
   화면 기준으로는 "얼마나 잘렸는가"를 잴 수 없다. 기각
3. **부품의 원래 면적 대비 노출 비율 30%** ← 선택

## 선택한 이유
잘림은 "이 부품이 원래 크기 대비 얼마나 남았는가"의 문제이지 "화면을 얼마나 차지하는가"의
문제가 아니다. 본 데이터는 촬영 각도와 확대율 편차가 커서(클로즈업 ~ 전체 샷) 화면 기준을
쓰면 같은 잘림 상태가 샷 타입에 따라 다르게 판정된다.

30%라는 값 자체는 새로 만든 것이 아니라 **파이프라인 문서 Step 01 의 원문 수치**다.
이번 결정은 임계값 신설이 아니라, 원문의 분모가 무엇인지를 코드와 문서에 못박은 것이다.

## 근거
- 파이프라인 문서 Step 01 `라벨링 제외 규칙` 원문:
  *"해당 부품의 정상 촬영 시 전체 면적 대비, 화면에 노출된 영역이 30% 미만(= 70% 이상
  잘림)이면 박스 생략. 30% 이상 노출되어 있으면 남은 영역만 박스 치고 truncated 로 표기"*
- 가이드 v2 `Capture Variance` — 촬영 각도(회전)·확대율(클로즈업 ~ 전체) 편차가 크다는 기술
- 코드 반영: `schemas/labeling_rules.py` 의 `VISIBLE_AREA_MIN`, `VISIBLE_AREA_BASIS`

## 한계 — 자동 계산식이 없다
분모가 "추정되는 전체 면적"이므로 좌표만으로는 계산할 수 없다. 라벨러는 같은 반의
잘리지 않은 다른 프레임을 기준 삼아 눈으로 추정한다.

이 추정 편차는 없앨 수 없고, **측정해서 관리한다.**
→ OQ-005: STEP 12 라벨러 간 일치도 검증에서 잘림 케이스를 따로 표본에 넣어
경계 케이스의 불일치율을 별도로 집계한다.

## 영향
- 라벨러 작업 지침서에 이 기준과 예시 이미지를 함께 배포해야 한다 (파이프라인 02 섹션)
- `truncated` / `occluded` / `ignore` 는 서로 다른 필드로 기록한다. 하나로 뭉치지 않는다

## 후속 작업
- 30% 경계 부근 예시 이미지를 현장 데이터에서 골라 지침서에 넣는다 (시드셋 라벨링 이후)
