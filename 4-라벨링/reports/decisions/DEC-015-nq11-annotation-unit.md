# DEC-015 — NQ-11: MCCB 접촉부의 annotation unit + 클래스별 단위 체계 도입

## 날짜
2026-08-27

## 문제
`접촉부` 는 상위 개념일 뿐이고, **무엇을 하나의 객체로 볼 것인가**가 클래스마다 다르다.
경계 문제가 아니라 **annotation unit 문제**다. 단위가 다르면 인스턴스 수가 달라지고,
mIoU·Kappa·mAP 가 전부 흔들린다. 라벨러 5명이 붙으면 즉시 불일치로 나타난다.

DEC-014 에서 정본 2종(개별 접속점)과 참고 1종(단자군)이 다르다는 것을 확인했고,
MCCB 접촉부는 `UNKNOWN` 으로 남겨 두었다.

## 결정

1. **MCCB 접촉부(#28) = 단자군 단위**로 확정한다. 단서는 아래 6항에 명시한다.
2. **클래스별 `annotation_unit` 을 코드에 정의**한다. `접촉부` 라는 상위 개념으로
   단위를 정하지 않는다.
3. P9 참고 라벨은 여전히 `reference` 등급이다. 이 결정은 라벨 승격이 아니다.

---

## 1. 가이드 자체 근거 — 가장 무거운 증거

`ACB&MCCB 반 전경` 이미지(가이드 18번)를 확대해 확인했다
(`experiments/seed_selection/guide_images/18_crop_left.png`).

차단기 10대가 랙에 배열된 사진이며, 박스가 두 종류로 그려져 있다.

```
적색 박스  기기 한 대의 외곽              -> 기기당 1개
청색 박스  좌·우 단자군 (한쪽 단자 전체)   -> 기기당 2개
```

**가이드 작성자 본인이 이 반 계열의 접촉부를 `단자군 스트립` 으로 그렸다.**
개별 볼트마다 박스를 친 것이 아니다.

### 단서 — 캡션은 `ACB 접촉부` 다
이미지 캡션은 `ACB&MCCB 반 전경 · ACB 접촉부(적/파랑)/MCCB(녹)/콘덴서(주황)` 이다.
즉 이 박스들은 **ACB 접촉부(#27)** 로 표기돼 있고, #28 MCCB 접촉부를 따로 그린 예시는
가이드에 없다. 다만 ACB 와 MCCB 는 같은 반의 같은 형태 기기이고, 사진에 찍힌 것은
몰드케이스 차단기 랙이다. **같은 계열의 접촉부 관행으로 본다.**

## 2. P9 참고 라벨의 정량 검증

P9 참고 라벨을 **정답으로 가정하지 않고** "어떻게 그려졌는가"만 측정했다.
접촉부가 있는 301장 / 1,777박스.

| 검증 축 | 결과 | 해석 |
|---|---|---|
| 기기당 접촉부 개수 | **중앙 2.00** (75% 가 1.5~2.5) | 좌우 각 1개 |
| 좌우 배치 균형 | 좌 847 / 우 930 (**비 0.91**) | 좌우 대칭 |
| 본체 박스 안에 완전 포함 | **89%** (1,584/1,777) | 기기 외곽 안쪽에 붙어 있다 |
| **접촉부 높이 / 본체 높이** | **중앙 0.922** (p25~p75 **0.87~0.97**) | 기기 세로 전체를 훑는 스트립 |

평균이 1.86 으로 중앙값보다 낮은 것은, 기기가 프레임에 잘려 한쪽 단자만 보이는
프레임이 섞였기 때문으로 보인다.

## 3. 정본과의 수치 대비 — 단위가 실제로 다르다

`접촉부 높이 / 본체 높이` 하나로 두 관행이 갈린다.

| 클래스 | 등급 | 쌍 | **세로비 중앙** | p25~p75 | 면적비 중앙 |
|---|---|---:|---:|---|---:|
| 몰드변압기 접촉부 (#03) | canonical | 983 | **0.462** | 0.28~0.75 | 0.088 |
| 변류기 접촉부 (#25) | canonical | 111 | **0.379** | 0.21~0.54 | 0.042 |
| **MCCB 접촉부 (#28)** | reference | 1,777 | **0.922** | **0.87~0.97** | 0.152 |

정본 2종은 본체 높이의 **절반 이하** — 접속점 하나를 감싼다.
MCCB 접촉부는 본체 높이의 **92%** — 단자 전체를 세로로 훑는다.
p25~p75 폭이 0.10 밖에 안 되어 1,777개가 매우 일관적이다.

## 5. 왜 그렇게 그렸는가 — 역추적 (INFERENCE)

가이드 종합표는 #28 MCCB 접촉부를 이렇게 적어 두었다.

> `28 MCCB 접촉부 ⚠️ **다른 접촉부와 구분이 안됨**`

랙에 차단기가 조밀하게 배열되면 인접 기기의 접점과 뒤섞여 개별 접점 단위로는
어느 기기의 것인지 가려내기 어렵다. **기기 단위로 묶으면 그 모호함이 사라진다.**
관행이 그렇게 굳은 이유로 설명이 되지만, **이것은 추론이며 문서 근거는 아니다.**

## 7. 결정 — MCCB 접촉부 = 단자군 단위

```
annotation_unit(MCCB 접촉부 #28) = TERMINAL_GROUP
```

```
기기 한 대당
  좌측 단자군 전체를 세로로 감싸는 박스 1개
  우측 단자군 전체를 세로로 감싸는 박스 1개
개별 단자·볼트마다 박스를 치지 않는다
```

### 근거의 무게
1. 가이드 자체 예시 이미지가 이 반 계열을 단자군으로 그렸다 (가장 무거움)
2. P9 1,777박스의 세로비 0.922 / p25~p75 0.87~0.97 — 매우 일관
3. 3현장·4건물·8세션에서 재현
4. 정본 2종(0.38·0.46)과 수치로 명확히 갈린다

### 남는 불확실성 (숨기지 않는다)
- 가이드 예시의 캡션은 `ACB 접촉부` 이고, #28 을 직접 그린 예시는 없다
- P9 라벨은 `reference` 등급이며 검수 이력이 없다 (NQ-6)
- P8 에는 적용하지 않는다

**되돌릴 수 있는 결정이다.** 시험 라벨링에서 불일치가 나오면 재검토한다.

## 8. 클래스별 annotation unit 체계 도입

`접촉부` 라는 상위 개념으로 단위를 정하지 않는다.
`schemas/classes_v2.py` 에 `ANNOTATION_UNIT` 을 추가했다.

| 단위 | 뜻 |
|---|---|
| `WHOLE_OBJECT` | 부품 하나를 통째로 감싼다 |
| `CONTACT_POINT` | 볼트로 조여진 접속 지점 하나하나 |
| `TERMINAL_GROUP` | 기기 한쪽 단자군 전체를 하나로 |
| `UNKNOWN` | 근거 없음. 확정하지 않는다 |

| 클래스 | 단위 | 근거 |
|---|---|---|
| 몰드변압기 접촉부 (#03) | `CONTACT_POINT` | canonical 1,365박스, 세로비 0.462 |
| 변류기 접촉부 (#25) | `CONTACT_POINT` | canonical 219박스, 세로비 0.379 |
| MCCB 접촉부 (#28) | `TERMINAL_GROUP` | 이번 결정 |
| 케이블헤드 (#14) | `WHOLE_OBJECT` | DEC-013 |
| 그 밖 접촉부 7종 | `UNKNOWN` | 라벨 실적 0건. 시드 라벨링 이후 판단 |
| 그 밖 부품 클래스 | `WHOLE_OBJECT` | 부품 단위가 자명한 클래스 |
