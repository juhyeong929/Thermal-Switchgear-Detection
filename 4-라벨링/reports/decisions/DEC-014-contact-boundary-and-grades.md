# DEC-014 — 접촉부 경계는 클래스별로 다르다 + 라벨 등급 명시

## 날짜
2026-08-27

## 결정 내용

1. **접촉부 계열에 공통 경계 규칙을 두지 않는다.** 클래스마다 라벨 단위가 다르다.
2. `DEC-011` 의 `접촉부는 단자군 단위` 를 **정정한다.** 과일반화였다.
3. P6·P9 참고 라벨에 `annotation_grade = reference` 를 명시한다.
4. 케이블헤드 엘보는 `elbow_policy = PENDING_EXPERT_REVIEW`, 베이스·취부는 `UNKNOWN`.
5. 작은 객체 임계값은 `candidate_threshold` 로만 둔다.

### 정정 — DEC-011 의 과일반화

DEC-011 에 이렇게 적었다.

> 가이드의 `접촉부` 는 **단일 금속 접점이 아니라 기능적으로 묶인 단자군 단위**로 읽는다.

**이 진술은 과했다.** 근거가 참고 등급 P9 한 클래스뿐이었다.
정본 2종(몰드변압기 접촉부·변류기 접촉부)은 **개별 접속점 단위**로 라벨되어 있다.

당시에도 "확인한 것은 MCCB 계열"이라고 단서를 달았지만, 표현이 일반 규칙처럼 읽혔다.
규격서(`bounding_box_boundary_spec.md`)에 정정을 명시했다.

### 확정 범위

| 클래스 | 단위 | 배포 |
|---|---|---|

## 2. 잘림 — 기존 정책과 실측이 일치한다

| 집합 | 박스 | 1변 접촉 | 2변 이상 |
|---|---:|---:|---:|
| 정본 P1/P3/P4 | 4,177 | 1,190 (28.5%) | 17 |
| 참고 P6 | 546 | 138 (25.3%) | 1 |
| 참고 P9 | 2,793 | 750 (26.9%) | 1 |
| **합계** | **7,516** | **2,078 (27.6%)** | **19 (0.25%)** |

1변 접촉은 흔하고(28%), 2변 이상은 사실상 없다(0.25%).
DEC-007 의 `노출 30% 미만이면 생략` 과 방향이 같다.
**`schemas/labeling_rules.py` 를 수정하지 않았다.**

## 3. 작은 객체 — 근거가 넓어졌지만 여전히 접촉부 한정

| 클래스 | 등급 | 초소형(면적<0.0015) |
|---|---|---:|
| 몰드변압기 접촉부 | canonical | 39 / 1,365 (2.9%) |
| 변류기 접촉부 | canonical | 4 / 219 (1.8%) |
| MCCB 접촉부 | reference | 21 / 1,778 (1.2%) |

면적 5퍼센타일 — 정본 0.0027 / 참고 0.0034.

이전에는 "MCCB 접촉부 한 클래스의 경험값"이라고 기록했는데,
**정본 2종이 추가되어 세 클래스가 같은 값대로 모인다.** 근거가 넓어졌다.

그러나 **셋 다 접촉부 계열이다.** 접촉부가 아닌 클래스의 작은 객체 사례가 없다.

```
candidate_threshold = 정규화 면적 0.003 (320x240 에서 약 15x15 px)
```

**공식 임계값으로 만들지 않는다.** 라벨러에게는 픽셀 수가 아니라
`식별 가능성` 기준으로 배포한다. → NQ-12

## 4. 중첩 · 겹침 — 확정

```
같은 인스턴스를 뜻하는 박스를 두 개 만들지 않는다.
서로 다른 물리적 객체라면 각각 만든다. 겹쳐 보인다고 그룹 박스로 묶지 않는다.
다른 클래스끼리의 겹침은 정상이다.
```

마지막 항목의 근거: 가이드 v2 `VCB 반 전경` 에서
**케이블헤드(적) 박스 안에 VCB 접촉부(주황) 박스가 들어간다.**

실측 — 같은 클래스 IoU ≥ 0.6 중첩이 참고 3,339박스 중 **1건**. 규칙이 지켜지고 있다.

## 5. 라벨 등급 명시

```
canonical   P1 / P3 / P4    4,177 박스   학습·지표의 기준
reference   P6 546 · P9 2,793 = 3,339    경계 규칙 검증·사례 추출 전용
```

참고 등급은 기술적으로 v2 승계가 가능하고(DEC-013 로 의미 동일성도 확인됐다),
그럼에도 **canonical 로 승격하지 않는다.** 사유는 품질이다.

| 승격 차단 사유 | 상태 |
|---|---|
| NQ-1 미작업 잔여 (보류 31장, A3 세션 44장) | 미해소 |
| 초소형·가로형 이상치 (P6 11개) | 미해소 |
| 중첩 박스 4개 | 미해소 |
| 검수 이력 부재 (NQ-6) | 미해소 |
| 범위 미달 추정 10% 남짓 (등가 쌍 ≥1.3배 28/251) | 미해소 |

`data/backup/P6_6ban` · `data/backup/P9_9ban` 에 스냅샷으로 보존돼 있다.
**어떤 경우에도 버리지 않는다.**

## 6. 케이블헤드 상태 표기

```
semantic mapping        = CONFIRMED
boundary policy         = MOSTLY CONFIRMED
expert-dependent items  = PENDING
    elbow_policy        = PENDING_EXPERT_REVIEW
    base_mount_policy   = UNKNOWN
```

`PENDING_EXPERT_REVIEW` 는 **제외 결정이 아니다.** 전문가 확인 전까지
라벨러가 임의 판단하지 않고 Skip 하여 검수로 넘긴다는 운영 규칙이다.

베이스·취부 구조는 가이드 예시에서 일관된 처리를 확인하지 못했다.
근거가 없으므로 `UNKNOWN` 을 유지한다.
