# DEC-016 — 정본(canonical) 라벨 감사 결과 (OQ-009)

## 날짜
2026-08-28

## 성격
**READ-ONLY 감사.** 라벨을 한 줄도 수정하지 않았다. 규격서도 고치지 않았다.
**규격을 기준으로 라벨을 감사했다.** 그 반대가 아니다.

## 왜 했는가
경계 규격서와 지침서는 **정본 라벨이 만들어진 뒤에** 썼다. 그런데 정본 4,177박스가
그 규격을 지키는지 확인한 적이 없다. 지키지 않는다면 `canonical` 이라는 지위 자체가
흔들리고, 라벨러에게 배포한 규칙과 학습 기준 데이터가 어긋나게 된다.

### 준수율 — 분모를 밝힌다

반 후보 클래스      4,177 / 4,177  = 100.0%

`초소형` 은 공식 임계값이 없어 PASS/FAIL 로 세지 않았다.

## C. CONTACT_POINT 준수 여부

좌표만으로는 **"하나의 물리적 접속점마다 박스 하나인가"를 확정할 수 없다.**
확정 가능한 것은 "장당 여러 개가 나오는가" 라는 정황뿐이다.

| 클래스 | 단위 | 박스 | 장당 중앙 | 장당 최대 | 감사 |
|---|---|---:|---:|---:|---|
| 몰드변압기 접촉부 | `CONTACT_POINT` | 1,365 | 3 | 7 | **CONSISTENT** |
| 변류기 접촉부 | `CONTACT_POINT` | 219 | 3 | 6 | **CONSISTENT** |

두 클래스 모두 한 장에 여러 개가 나온다. 단자군으로 묶었다면 장당 1~2개여야 한다.

### 시각 확인
`contactpoint_P3P4_13_A2_B1_P3_2022-06-03_IR1_00008.png` —
변류기 접촉부 3개가 **볼트 접속점마다 하나씩** 그려져 있다. 본체나 도체를 삼키지 않았다.
`contactpoint_P1_11/12` 도 같은 형태다.

**질문별 답 (표본 범위 안에서)**
1. 접속점마다 하나인가 — 표본에서는 그렇다. 전수 확정은 불가
2. 여러 접속점을 하나로 합친 사례 — 표본에서 발견하지 못했다
3. 하나를 여러 박스로 나눈 사례 — **20건의 중복이 이에 해당할 수 있다** (A 항목)
4. 본체·도체까지 포함 — 표본에서 발견하지 못했다. 면적비(본체 대비 0.074/0.042)도 작다

## D. 잘림 30% 규칙 — **전량 UNDETERMINABLE**

규칙의 분모는 `해당 부품의 정상 촬영 시 전체 면적` 이다.
**bbox 좌표만으로는 원래 면적을 알 수 없다.** 따라서 30% 판정 자체가 불가능하다.
이것은 라벨의 문제가 아니라 **규칙의 성질**이다(DEC-007 이 이미 밝혀 둔 한계).

정확히 측정 가능한 것은 프레임 접촉뿐이다.

| 구분 | 건수 |
|---|---:|
| 접촉 없음 | 2,970 |
| 1변 이상 접촉 | **1,207 (28.9%)** |
| 2변 이상 접촉 | **17** |

2변 이상 17건을 개별 지적 사항으로 남겼다. 이들이 30% 규칙을 어겼는지는
**사람이 이미지를 봐야 판정 가능**하다.

`UNKNOWN` 은 위반으로 세지 않았다. `WHOLE_OBJECT` 는 좌표만으로 준수를 판정할 수 없다.

## F. 클래스/라벨 의미 일치

**자동 판정하지 않았다.** 이미지 의미 판정을 자동화했다고 주장하지 않는다.
표본 14장을 열어 육안으로 확인한 범위에서, 라벨 클래스와 대상 형태가
어긋나 보이는 사례는 발견하지 못했다. **이는 표본 관찰이지 전수 검증이 아니다.**

## 핵심 지표

```
canonical_total            = 4,177

duplicate_confirmed        = 20
duplicate_suspect          = 3

small_candidate            = 238   (공식 위반 아님)

contact_point_expected     = 1,584  (몰드변압기 1,365 + 변류기 219)
contact_point_pass         = 0      (좌표만으로 확정 불가)
contact_point_consistent   = 1,584  (정황상 일치)
contact_point_fail         = 0
contact_point_undeterminable = 1,584

truncated_edge_touch       = 1,207
truncated_2edge_plus       = 17
truncated_rule_violations  = 판정 불가
truncated_undeterminable   = 1,207

판정 가능 분모             = 4,177 (제외·후보) / 3,444 (중복 쌍)
overall_fail               = 20
overall_fail_rate          = 0.48%  (분모: 중복 검사 쌍 3,444 중 20)
undeterminable_rate        = 28.9%  (분모: 전체 4,177 중 잘림 판정 불가 1,207)
```

> **주의 — `0.48%` 를 품질 점수로 읽지 않는다.**
> 이 값은 `같은 클래스 중복` 규칙 하나에 대해 검사 쌍 3,444 를 분모로 계산한 것이다.
> **"annotation 품질이 99.52%" 라고 표현하면 안 된다.** 초소형(238)과 잘림(1,207)은
> 판정 불가·기준 미정이 섞여 있어 전체 품질로 환산할 수 없다.

**`overall_pass_rate` 를 단일 수치로 내지 않았다.** 규칙마다 분모가 다르고,
판정 불가를 PASS 에 섞으면 실제보다 좋아 보이기 때문이다.

## CASE A vs CASE B 판정

| 발견 | 판정 | 근거 |
|---|---|---|
| 같은 클래스 중복 20건 | **CASE A — 라벨 품질 문제** | 규격 이전에도 같은 인스턴스 이중 라벨은 잘못이다. 시각 확인에서 같은 접속점 위 포개진 박스 확인 |
| 초소형 238건 | **CASE B 쪽** | 규격에 공식 임계값이 없다. 대상이 실제로 작은 것으로 보인다. 규격이 아직 정하지 않은 영역 |
| 잘림 판정 불가 1,207건 | **규격의 성질** | 좌표만으로 판정 불가는 규칙 설계상 예정된 한계(DEC-007) |
| CONTACT_POINT | **일치 정황** | 규격과 라벨이 어긋나지 않는다 |

**규격 설계 문제로 볼 만한 것은 초소형 항목 하나다.** 나머지는 규격과 라벨이 맞는다.

## 결론

정본 4,177박스는 **제외 클래스·반 후보 클래스에서 위반 0건**이고,
`CONTACT_POINT` 단위도 규격과 어긋나지 않는다.
명백한 위반은 **같은 클래스 중복 20건(0.48%)** 뿐이며 전부 P1 에 몰려 있다.

**30장 시험 라벨링을 막을 이유는 없다.** 다만 중복 20건은 정본에 남겨 두면
학습 시 인스턴스가 두 번 세어지므로, 시험과 **병행해서** 처리 방침을 정해야 한다.

- ~~중복 20건을 어떻게 할지~~ → **DEC-017 로 처리됨: QUARANTINE_PENDING_REVIEW**

- 2변 접촉 17건의 30% 규칙 판정 → 사람이 이미지 확인 필요 → OQ-014
