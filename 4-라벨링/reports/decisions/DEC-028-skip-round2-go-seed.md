# DEC-028 — 2차 시험 회차를 취소하고 400장 시드 라벨링으로 넘어간다

```
상태        승인 대기 — 아래 승인란이 비어 있으면 이 문서는 아직 결정이 아니다
승인란      결정자: __________   날짜: __________
```

## 날짜
2026-09-03

## 결정 내용

```
round 2 (v2.0 · annotator_D · annotator_E)   PENDING -> CANCELLED
annotator_E 회수                              받지 않는다
다음 단계                                      400장 시드 본 라벨링
```

## 왜

시험을 더 돌려서 얻을 것보다 본작업을 시작해서 얻을 것이 크다는 판단이다.
v1 조건에서 이미 **4명**의 결과가 있고(round 1 A·B·C + round 3 D), 시험이 답하려던
질문 대부분이 그 안에서 재현됐다.

```
NQ-15 반 정보 비공개 문제   4/4 재현 (후보 밖 박스 A 3 · B 23 · C 3 · D 7)
NQ-14 P3 몰드타입 PT        3명이 각각 3박스 — 반을 감춘 조건에서 같은 판단
scope=object 미사용         4/4
작업시간                    22 · 60 · 44 · 38분 -> 400장 추정 9.1시간(1인)
```

## 이 결정이 치르는 대가 — 숨기지 않는다

**v2 개선 규칙의 효과가 한 번도 측정되지 않은 채 본작업에 들어간다.**

```
v2 의 두 가지 변경   반 정보 공개 · 반별 CVAT task
측정된 조건          v1(반 비공개 · 전체 클래스 목록) 4명뿐
```

지침서 v2 는 §1 에서 "자기 반 목록에 없는 클래스는 그리지 않습니다" 를 가장 강한
규칙으로 두고, 반별 task 는 그 규칙을 **지킬 수단**으로 도입됐다. 그 수단이 실제로
후보 밖 박스를 줄이는지는 아직 관측되지 않았다.

따라서 다음이 성립한다.

| | 상태 |
|---|---|
| C-2 (라벨러 간 일치도) | v1 조건 4명 값만 존재. **v2 조건 값 없음** |
| BLK-3 (Kappa 대표성) | 이 경로로는 닫히지 않는다 |
| NQ-15 판정(A-1) | 결정은 했으나 효과는 미검증 |

**이 사실을 성능 보고에서 빼지 않는다.** "5인 시험을 거쳤다" 로 쓸 수 없고,
"v1 조건 4인 · v2 조건 미측정" 으로 적는다.

## 남은 길 — 본작업 안에서 측정한다

별도 회차 없이도 C-2 를 낼 수 있다. **400장 중 일부를 두 사람에게 겹쳐 배정**하면
본작업 산출물에서 그대로 일치도가 나온다.

```
겹침 구간 없음   C-2 는 영구히 v1 조건 4명 값에 머문다
겹침 구간 있음   본작업이 곧 v2 조건 측정이 된다. 추가 인건비는 겹친 장수만큼
```

겹침 구간을 둘 것인지, 둔다면 몇 장을 어느 반에서 뽑을 것인지는 배포 설계에서
정한다. **정하지 않으면 없는 것으로 간주한다** — 이 문서는 그 선택을 열어 둘 뿐이다.
