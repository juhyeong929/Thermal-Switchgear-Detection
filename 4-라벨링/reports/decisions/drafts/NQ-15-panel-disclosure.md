# [초안] NQ-15 — 라벨러에게 반(Panel) 정보를 알려 줄 것인가

```
상태        DRAFT — 승인 대기
승인란      결정자: __________   날짜: __________   DEC 번호: __________
대상        open_questions.csv  NQ-15
작성        2026-09-01 · 2차 실무 감사 후속
```

## 문제

지침서 v1 §1 은 라벨링 규칙 중 **가장 강하게 강조된 항목**이다.

> "자기 반의 목록에 없는 클래스는 그리지 않습니다.
> **이것만 지켜도 오라벨이 크게 줄어듭니다.**"

그런데 배포물(`trial_instructions.md` "보내는 것" 5종)에는 반 정보가 없고,
`deploy_checklist_D_E.md` 는 "반 정보를 감춘 상태 유지" 를 배포 조건으로 못박았다.

**즉 지침서에서 가장 중요한 규칙이 적용 수단 없이 배포됐다.**

## 실측 근거

1차 시험(A·B·C 3인 · 30장)에서 **3/3 재현**됐다.

```
A09 (P4-MOF&PT반)
  A  비한류형 전력퓨즈 3박스   (P4 후보 O)
  B  한류형 전력퓨즈  3박스   (P4 후보 X)
  C  LA            3박스   (P4 후보 X)
```

| | A | B | C |
|---|---:|---:|---:|
| 후보 밖 클래스 박스 | 3 | **23** | 3 |

반별 지표를 뽑으면 후보 수와 일치도의 관계가 더 분명하다
(`agreement_by_panel_2026-09-01.csv`).

| 반 | 배포 클래스 | 짝지어진 박스 | Kappa |
|---|---:|---:|---:|
| P9 | 2종 | 68~82 | **1.000** |
| P4 | 5종 | 3~7 | **0.000~0.417** |

## 선택지

| | 방식 | 장점 | 대가 |
|---|---|---|---|
| **(1)** | **반 이름 공개 + CVAT 반별 task 분리** | §1 이 작동. **본작업 조건과 동일** | 후보가 1~2종인 반은 사실상 선택지가 없어 Kappa 가 과대평가된다 |
| (2) | 반 비공개 + CVAT 라벨 목록만 반별 제한 | 후보 밖 클래스를 물리적으로 못 그림 | 라벨러가 이유를 모름. 본작업 조건과 다름 |
| (3) | 반 비공개 유지 + §1 을 지침서에서 삭제 | 문서 모순은 사라짐 | NQ-15 가 그대로 재현. 현상 유지 |

## 결정 (안)

```
decision = DISCLOSE_PANEL_AND_SPLIT_CVAT_TASKS      # 선택지 (1)
```

**근거.** "반을 알려주면 후보 목록에서 답을 추측할 수 있다" 는 우려는 두 질문을 섞은 것이다.

| 질문 | 이 프로젝트의 목표인가 |
|---|---|
| 열화상만 보고 부품을 식별할 수 있는가 | **아니다** (연구 질문) |
| 실제 운영 절차에서 라벨이 일관되는가 | **그렇다** |

본작업에서 라벨러는 당연히 자기 반을 안다. 후보를 좁히는 것은 **부정행위가 아니라
운영 규칙 그 자체**다. 그 조건에서 재는 것이 맞다.

## 함께 정하는 것 — 지표 왜곡 방지

선택지 (1)의 대가(후보가 좁은 반의 Kappa 과대평가)는 **측정 설계로 관리한다.**

```
· 반별 Kappa / count agreement / Skip / paired coverage 를 자동 산출한다
· 배포 클래스 2종 이하 · 비교 5장 미만 · paired coverage 70% 미만인 반에는
  주의 문구를 자동으로 붙인다
· pooled Kappa 를 단독 인증 근거로 쓰지 않는다  -> C2-trial-round-separation 초안
```

## 영향

**이미 코드에 반영된 것**

| 무엇 | 어디 |
|---|---|
| 반별 CVAT task·라벨 정의·`obj.names` 기대값 생성 | `scripts/build_cvat_tasks.py` |
| 반별 일치도 지표 (별도 파일. 기존 CSV 형식 불변) | `scripts/agreement.py` |
| 배포 클래스 = 후보 − 단위 미확정 | `classes_v2.deployable()` |
| 배포 절차 갱신 | `reports/labeling/deploy_checklist_D_E.md` |

**아직 하지 않은 것**

- `open_questions.csv` NQ-15 닫기 — **승인 후 사람이 한다**
- 지침서 v2 작성 (§1 표는 `generated/panel_class_table.md` 를 그대로 쓴다)

## 되돌리는 법

`build_cvat_tasks.py` 를 쓰지 않고 단일 프로젝트 + 전체 라벨 목록으로 되돌리면 된다.
클래스 스키마·시드·정본 라벨은 이 결정에 영향받지 않는다.

## 주의 — v1 데이터는 이 결정의 적용 대상이 아니다

A·B·C 는 **반 비공개 조건**에서 작업했다. 이 결정은 **v2 부터** 적용된다.
v1 결과를 이 결정으로 재해석하거나 수정하지 않는다.
