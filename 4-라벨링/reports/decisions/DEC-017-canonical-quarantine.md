# DEC-017 — 정본 규격 위반 박스의 격리 (OQ-013)

## 날짜
2026-08-28

## 결정 내용

DEC-016 감사에서 나온 **같은 클래스 중복 20쌍**을 다음처럼 처리한다.

```
canonical_original        정본 파일은 그대로 둔다. 수정하지 않는다
        ↓
QUARANTINE 목록에 등재    data/labeling/quarantine/canonical_quarantine.csv
        ↓
학습셋 구축 시에만 제외    load_quarantine() 이 걸러 준다
```

상태: **`QUARANTINE_PENDING_REVIEW`**

## 왜 삭제하지 않는가

두 박스 중 **어느 쪽이 옳은지 사람이 재검수하지 않았다.**
그 상태에서 한쪽을 지우면 근거 없는 수정이 하나 더 늘어날 뿐이다.
감사에서 "규격을 라벨에 맞추지 않는다"고 한 원칙이 반대 방향에도 똑같이 적용된다 —
**근거 없이 라벨을 고치지도 않는다.**

그래서 **두 박스를 모두 등재했다.** 한쪽만 고르지 않았다.

## 격리 내역

| 항목 | 값 |
|---|---:|
| 중복 쌍 | 20 |
| 등재 행 | 40 (쌍마다 두 박스) |
| 고유 박스 | **37** (한 박스가 두 쌍에 걸친 경우 3건) |
| 이미지 | 17 |
| 정본 대비 | **0.89%** (4,177 중 37) |
| 학습에 쓰이는 박스 | **4,140** |

반별 — P1 40행. **P3·P4 는 0건.**
클래스별 — 몰드변압기 접촉부 34 · 철심부 4 · 에폭시 표면 2.

## 등재 서식

```
image · box_index · panel_id · class_id · class_name
quarantine_reason · detail · pair_with
status · resolved_by · resolution · source_audit
```

`box_index` 는 정본 txt 의 줄 번호(0-base)다.
사람이 재검수해 옳은 쪽을 정하면 그 행의 `status` 를 `해제` 로 바꾼다.
`load_quarantine()` 은 `해제` 가 아닌 행만 제외 대상으로 돌려준다.

## 해석상 주의 — 0.48% 를 품질 점수로 읽지 않는다

감사에서 나온 `0.48%` 는 **같은 클래스 중복 규칙 한 가지**에 대해,
**검사한 박스 쌍 3,444 를 분모로** 계산한 값이다.

> **"annotation 품질이 99.52%" 라고 표현하면 안 된다.**

초소형(238건)과 잘림(1,207건)은 판정 불가·기준 미정이 섞여 있어
전체 품질 점수로 환산할 수 없다. 규칙별로 분모를 분리해 읽어야 한다.

이 문장을 `DEC-016` 과 교수님 보고서에도 넣었다.

## 정본의 지위

**정본 4,177 박스는 그대로 유지한다.** 격리는 학습셋 구축 단계에서만 적용된다.
감사·격리 이후에도 `data/labeling/reviewed` 의 파일 내용은 변하지 않았다.

## 영향
- 학습셋을 만들 때 `load_quarantine()` 을 반드시 거쳐야 한다
- 격리 해제는 사람의 재검수 결과로만 이루어진다
- OQ-013 상태: `QUARANTINE_PENDING_REVIEW`

## 후속
- 17장을 사람이 열어 어느 박스가 옳은지 판정 → `status` 갱신
- OQ-014(2변 접촉 17건)는 별개 사안. 아직 격리하지 않았다
